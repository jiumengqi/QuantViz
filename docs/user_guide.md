# 股票分析与量化投资平台用户指南

## 1. 平台介绍

股票分析与量化投资平台是一个综合性的金融分析工具，旨在帮助投资者进行股票分析、量化策略回测和投资组合优化。平台提供了丰富的技术分析指标、回测系统、金融模型和API接口，满足不同层次投资者的需求。

### 主要功能

- **用户管理**：注册、登录、个人资料管理、密码重置
- **股票数据**：实时行情、历史数据、指数数据
- **技术分析**：多种技术指标、图表分析、相关性分析
- **量化回测**：多种策略模板、自定义策略、回测结果分析
- **金融模型**：Markowitz投资组合优化、Black-Scholes期权定价、债券定价模型、风险价值(VaR)计算、时间序列预测模型
- **API接口**：JWT认证、数据接口、策略接口

## 2. 快速开始

### 2.1 系统要求

- Python 3.7+
- Flask 2.0+
- 现代Web浏览器（Chrome、Firefox、Safari、Edge）
- 互联网连接（用于数据获取）

### 2.2 安装与运行

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd 股票分析与量化投资平台
   ```

2. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

3. **配置API密钥**
   在 `config.py` 文件中配置您的Tushare API密钥：
   ```python
   API_KEYS = {
       'tushare': 'your-tushare-api-key',
       # 其他API密钥
   }
   ```

4. **运行应用**
   ```bash
   python app.py
   ```

5. **访问平台**
   打开浏览器，访问 `http://127.0.0.1:5000`

## 3. 用户管理

### 3.1 注册账户

1. 点击首页右上角的"注册"按钮
2. 填写以下信息：
   - 用户名：3-20个字符，只能包含字母、数字和下划线
   - 邮箱：有效的邮箱地址
   - 密码：至少8位，包含大小写字母和数字
   - 确认密码：再次输入密码
3. 点击"注册"按钮
4. 注册成功后，系统会自动跳转到登录页面

### 3.2 登录系统

1. 点击首页右上角的"登录"按钮
2. 输入用户名和密码
3. 可选：勾选"记住我"，下次访问时自动登录
4. 点击"登录"按钮
5. 登录成功后，系统会跳转到首页

### 3.3 忘记密码

1. 在登录页面点击"忘记密码？"链接
2. 输入注册时使用的邮箱地址
3. 点击"发送重置链接"按钮
4. 系统会生成一个密码重置链接并显示在页面上
5. 点击该链接，进入密码重置页面
6. 输入新密码并确认
7. 点击"重置密码"按钮
8. 密码重置成功后，系统会跳转到登录页面

### 3.4 个人资料

1. 登录后，点击右上角的用户名，选择"个人资料"
2. 查看您的账户信息，包括用户名、邮箱、注册时间、最后登录时间等

### 3.5 管理员功能

**注：只有管理员账户才能访问这些功能**

1. 登录后，点击右上角的用户名，选择"管理员面板"
2. 在管理员面板中，您可以：
   - 查看所有用户列表
   - 编辑用户信息（邮箱、角色、账户状态）
   - 删除用户账户

### 5.1 技术指标

1. 点击顶部导航栏的"分析"菜单
2. 选择要分析的股票

4. 选择时间范围

6. 查看股票之间的相关性矩阵和热力图

## 6. 量化回测

### 6.1 策略模板

1. 点击顶部导航栏的"回测"菜单
2. 选择"策略模板"
3. 选择要使用的策略（如均线交叉、RSI、MACD、布林带、KDJ、CCI、均值回归、动量策略等）
4. 输入股票代码
5. 设置策略参数
6. 设置回测参数（初始资金、时间范围、手续费等）
7. 点击"开始回测"按钮
8. 查看回测结果，包括收益率、最大回撤、交易次数等
9. 查看回测历史和交易记录

### 6.2 新增策略说明

#### 均值回归策略
- **原理**：基于价格偏离均值后会回归的假设
- **参数**：计算均值和标准差的周期、偏离阈值
- **信号**：价格低于均值减去阈值倍标准差时买入，高于均值加上阈值倍标准差时卖出

#### 动量策略
- **原理**：基于价格趋势会延续的假设
- **参数**：计算动量的回溯期、持仓期
- **信号**：过去N天收益率为正时买入并持有M天，为负时卖出

### 6.3 自定义策略

1. 点击顶部导航栏的"回测"菜单
2. 选择"自定义策略"
3. 编写策略代码（使用Python语言）
4. 输入股票代码
5. 设置回测参数
6. 点击"开始回测"按钮
7. 查看回测结果

## 7. 金融模型

### 7.1 Markowitz投资组合优化

1. 点击顶部导航栏的"模型"菜单
2. 选择"Markowitz投资组合"
3. 输入多个股票代码
4. 设置时间范围
5. 点击"优化"按钮
6. 查看最优投资组合权重、有效前沿和风险收益特征

### 7.2 Black-Scholes期权定价

1. 点击顶部导航栏的"模型"菜单
2. 选择"Black-Scholes定价"
3. 输入期权参数（标的资产价格、执行价格、到期时间、无风险利率、波动率）
4. 点击"计算"按钮
5. 查看期权理论价格和希腊字母值

### 7.3 风险价值(VaR)计算

1. 点击顶部导航栏的"模型"菜单
2. 选择"风险价值"
3. 输入收益率数据
4. 设置置信水平、时间范围和其他参数
5. 点击"计算"按钮
6. 查看风险价值(VaR)、条件风险价值(CVaR)、下行风险等多种风险指标

### 7.4 债券定价模型

1. 点击顶部导航栏的"模型"菜单
2. 选择"债券定价"
3. 输入债券参数（面值、票面利率、到期年限、到期收益率、复利频率）
4. 选择债券类型（附息债券/零息债券）
5. 点击"计算"按钮
6. 查看债券价格、麦考利久期、修正久期和凸性

### 7.5 时间序列预测模型

1. 点击顶部导航栏的"模型"菜单
2. 选择"预测模型"
3. 选择预测模型类型（ARIMA/GARCH）
4. 输入时间序列数据
5. 设置预测步数和模型参数
6. 点击"运行模型"按钮
7. 查看预测结果、置信区间和模型摘要

## 9. 常见问题

### 9.1 登录问题

- **账户被锁定**：如果连续多次输入错误密码，账户会被锁定15分钟。请15分钟后再试，或联系管理员解锁。
- **忘记密码**：使用"忘记密码"功能重置密码。

### 9.2 数据问题

- **数据加载失败**：检查网络连接，或稍后再试。
- **数据不准确**：平台数据来源于第三方API，可能存在延迟或误差。

### 9.3 回测问题

- **回测速度慢**：回测大量数据时可能需要较长时间，请耐心等待。
- **策略不盈利**：回测结果仅供参考，不代表未来收益。

### 9.4 其他问题

- **页面显示异常**：尝试刷新页面，或清除浏览器缓存。
- **功能不可用**：检查账户权限，或联系管理员。
